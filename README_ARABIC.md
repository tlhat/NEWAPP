# مشروع تطبيق حنين كيدز (Haneen Kids v2.0) — النسخة الكاملة الجاهزة لاستقبال الفيديوهات

يحتوي هذا المجلد على الكود المصدري الكامل والمتكامل لتطبيق **حنين كيدز (Haneen Kids)** المبني بإطار **Flutter**، والمجهز بالكامل من شاشات الترحيب وتسجيل الحسابات وتسجيل الدخول وإدارة ملفات الأطفال، وصولاً إلى مشغل الفيديوهات العمودي التفاعلي واستوديو استقبال الفيديوهات السحابي والمحلي.

---

## 🌟 المميزات المكتملة في التطبيق

1. **شاشة البداية والترحيب التفاعلية (Splash & Onboarding)**:
   - شاشة تمهيدية تشرح للوالدين فلسفة التطبيق (محتوى هادئ، فطام ذكي عن الشاشة، وأنشطة واقعية).
2. **نظام حسابات ومصادقة متكامل (Full Auth Flow)**:
   - **إنشاء حساب جديد للوالدين (Sign Up)**: الاسم، البريد الإلكتروني أو رقم الهاتف، كلمة المرور، رمز الحماية الأبوي (PIN من 4 أرقام)، وإعداد ملف الطفل الأول.
   - **تسجيل الدخول (Sign In)**: مع خاصية حفظ الجلسة تلقائياً، استعادة كلمة المرور، وزر الدخول السريع بحساب تجريبي جاهز.
   - **ربط اختياري بواجهة برمجية (REST API Auth)**: إمكانية إدخال رابط سيرفر خارجي للمصادقة في حال رغبتك بربط الحسابات بقاعدة بيانات خارجية مستقبلاً.
3. **إدارة ملفات متعددة للأطفال (Multi-Child Profiles)**:
   - إمكانية إضافة أكثر من طفل داخل حساب الوالدين، وتخصيص الفئة العمرية، الرمز التعبيري، والحد اليومي للمشاهدة لكل طفل، مع تتبع مستقل للنجوم والأنشطة المنجزة.
4. **مشغل الفيديو العمودي الكامل (`video_player`)**:
   - تشغيل تلقائي للفيديوهات بصيغ `MP4` أو `HLS (.m3u8)` عند السحب العمودي.
   - أزرار التحكم (إيقاف/تشغيل باللمس، كتم/تشغيل الصوت، شريط تقدم الفيديو، وإعادة المحاولة عند انقطاع الاتصال).
   - شريط فلترة الأقسام الخمسة (`كل القصص`، `قصص النوم`، `سلوكياتي`، `فصاحة ونطق`، `لماذا وكيف؟`، `افعلها بيدك`).
   - نافذة **«ردد معي»** للتفاعل الصوتي باللغة العربية الفصحى وكسب النجوم.
   - نافذة **«نشاط البطل الواقعي»** لتشجيع الطفل على تنفيذ مهمة حركية أو سلوكية خارج الشاشة.
   - **فلتر المساء الدافئ** لتقليل الإضاءة الزرقاء قبل النوم، و**ستارة النوم الهادئة** التي تغلق المشاهدة بلطف عند انتهاء الحصة اليومية.
5. **بوابة الوالدين واستوديو استقبال الفيديوهات (Parental Gate & Video Receiver)**:
   - محمية بمعادلة حسابية ذكية أو الرمز السري للوالدين (PIN).
   - **طريقتان لاستقبال الفيديوهات فوراً بدون تعديل الكود**:
     1. **الربط السحابي (JSON Feed / API URL)**: ضع رابط أي ملف JSON مرفوع على GitHub أو Firebase أو استضافتك الخاصة (راجع ملف `sample_videos_feed.json` المرفق كنموذج جاهز) واضغط **«مزامنة الفيديوهات الآن»** ليقوم التطبيق بسحب الفيديوهات وتحديثها فوراً.
     2. **الإضافة المباشرة من داخل التطبيق**: نموذج كامل لإضافة أي فيديو جديد (العنوان، الوصف، القسم، الفئة العمرية، الجملة التفاعلية، النشاط الواقعي، ورابط الفيديو المباشر `mp4` أو `m3u8`) مع إمكانية تصدير القائمة كملف JSON.

## 📦 كيف ترفع الفيديوهات وتغذي التطبيق؟

لديك 3 خيارات مرنة جداً:
1. **من خلال ملف JSON سحابي (الأسهل للإدارة عن بُعد)**:
   - ارفع ملف `sample_videos_feed.json` الموجود في المشروع إلى مستودع GitHub أو استضافتك، وضع روابط فيديوهاتك في حقل `"streamUrl"`.
   - افتح التطبيق -> **بوابة الوالدين** -> تبويب **استقبال الفيديوهات** -> الصق رابط الـ JSON واضغط **مزامنة الآن**.
2. **من داخل لوحة تحكم التطبيق مباشرة**:
   - افتح **بوابة الوالدين** -> **إضافة فيديو جديد** -> أدخل رابط الفيديو والبيانات واضغط حفظ.
3. **تغيير الرابط الافتراضي في الكود قبل البناء**:
   - في ملف `lib/main.dart` يمكنك وضع رابط الـ API أو ملف الـ JSON الخاص بك في المتغير `kDefaultRemoteFeedUrl` ليقوم التطبيق بجلب فيديوهاتك تلقائياً لكل المستخدمين فور فتح التطبيق.

## 🚀 كيف تستخرج ملف `app-release.apk` جاهز للتثبيت عبر GitHub Actions؟

1. أنشئ مستودعاً جديداً (New Repository) على موقع GitHub.com.
2. ارفع جميع ملفات هذا المجلد إلى المستودع (بما في ذلك مجلد `.github/workflows/build_apk.yml` الذي يقوم تلقائياً بتفعيل صلاحيات الإنترنت وتشغيل الفيديو في نسخة الأندرويد النهائية).
3. اضغط على تبويب **Actions** في أعلى المستودع، ثم اختر **Build Android APK** واضغط **Run workflow**.
4. بعد انتهاء البناء، حمّل ملف `haneen-kids-release-apk` وثبّته مباشرة على أي هاتف أندرويد.
